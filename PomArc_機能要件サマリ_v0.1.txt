# PomArc 機能要件サマリ v0.1
最終更新: 2025-10-28（JST） / 参照元: PomArc 要件定義書 v0.1

## 表記
- [Pro] は課金プラン専用機能を示す

## 画面レイアウト（トップ→ボトム）
- 最上部: 広告バナー
- その下: 日付表示 / 左端にプロフィール / 右端に設定
- 中央: 左カラムにTodoリスト / 右カラムにDayスケジュール
- 中央下段: カレンダー
- 最下部: テンプレ作成 / Todo作成 / レポート
 - 注: 「/」は同一行の並列要素

## Todo作成
- 起点: 「Todo作成」ボタン
- フィールド
  - タスク名: 必須
  - 開始日: 任意（SRS使用時は必須）/ デフォルト=現在日 / カレンダー日付を長押し→「Todo作成」でその日付を自動選択
  - 時間指定: 任意 / デフォルト=現在時刻 / Dayスケジュールの時間を長押し→「Todo作成」でその時間帯を自動選択
  - カテゴリ: 任意 / テンプレで登録済みカテゴリから選択
  - SRS: 任意 / テンプレ作成で用意した間隔から選択
  - 範囲: 任意（例: 問題集のページ範囲など）
  - メモ: 任意
- アクション
  - 作成: Todoを作成しTodoリストへ反映
  - 今すぐ開始: 開始日と時間指定を現在に設定し、タイマー画面へ遷移

## Todoリスト
- 表示: Todo作成で作ったタスクを一覧表示（タスク名を大きく、カテゴリ/範囲/N回目を小さく、右端にチェック）
- 拡大: ホームからタップでリストを拡大表示
- ジェスチャ: 右スワイプ=削除 / 左スワイプ=編集・並び替え
- 遷移: タスク中央タップで詳細→タイマー画面へ

## Dayスケジュール
- 表示: 時間指定タスクを表示（タスク名大/カテゴリ・範囲・N回目は小）
- 拡大: ホームからタップで拡大表示
- ジェスチャ: 右スワイプ=削除 / 左スワイプ=編集・並び替え
- 遷移: タスク中央タップでTodoリストへ移動→詳細→タイマー画面へ
- 操作: スクロール可能 / 空白時間を長押し→「Todo作成」でその時間帯を自動選択

## カレンダー
- 表示: 年号・月 / 日時指定のタスク
- 拡大: ホームからタップで拡大表示
- 連動: 日付タップでホームの日付も切替→当日のTodoリストとDayスケジュールへ同期
- 作成: 日付を長押し→「Todo作成」でその日付を自動選択



## 連携
- Todoリスト / Dayスケジュール / カレンダーのタスクは相互リンク

## テンプレ作成
- SRS間隔: 忘却曲線/数日ごと/毎日/曜日ごとなどを設定可能
  - 無料: 忘却曲線以外に最大3つまでカスタム可能 / [Pro] 上限解放
- カテゴリ: 大-中-小の三段階で作成（例: デート / 運動-筋トレ / 学習-数学-問題集）

## タイマー
- 種類: ポモドーロ / カウントダウン / ストップウォッチ
- ポモドーロ: 25+5分 または 50+10分 を選択
- カウントダウン: 任意時間を設定可 / 休憩/再開を1タップで切替 / リセットあり
- ストップウォッチ: 休憩/再開を1タップで切替 / リセットあり
- 記録: 「記録」ボタンでレポートへ保存


## 日付表示
- 中央タップ: Dayスケジュールとカレンダーを現在日時へ戻す
- ▶◀ボタン: 日付の前後移動


## アクティビティ (Activity)
- コンセプト: 能動的な分析と振り返り。
- Analytics (分析):
  - 可視化: 棒グラフで「消費時間」と「Todo数」を表示。
  - カテゴリ別: カテゴリごとの消費時間・Todo数を可視化。
  - 期間切り替え: 今日 / 今週 / 今月 / 今年 / すべて。
- History (履歴):
  - 全Todo管理: アプリ内で作成した全てのTodo（完了・未完了問わず）をリスト表示。
  - 操作: フィルタリング（カテゴリ/ステータス）、削除機能。
- カレンダー (ホーム画面):
  - ヒートマップ: 活動量（完了タスク数や学習時間）に応じて日付の背景色を変化させ、継続を可視化。

## プロフィール
- アカウント管理
- その他は随時追加



## 認証/アカウント
- 匿名利用を許可し、メール/Apple/Googleサインアップで任意にアカウント化。サインアップ時に匿名データを移管。

## 広告
- 配信方針: 画面上部固定バナーのみ / タイマー中はレイアウト固定 / 全画面広告禁止
- SDK/同意: AdMob / ファミリー向け設定 / ATT・CMPで同意取得

## 課金（Pro）
- 提供: 広告削除 / 多端末同期 / 詳細統計 / SRSカスタム / エクスポート無制限 など
- 価格: 月額¥250 / 年額¥1,500
- 決済: iOS/Android = 各Store IAP / Web = Stripe想定

## 設定
- テーマ: ライト / ダーク / 自動
- 言語: 日本語 / 英語（段階的に追加言語を展開）

## データエクスポート
- CSVエクスポート（タスク/セッション/復習ログ）に対応。ユーザー単位1リクエスト/分、同時実行1件。大容量はバックグラウンド生成＋署名URL（有効15分）。

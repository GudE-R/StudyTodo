# Mobile App Functional Requirements (Draft)

本ドキュメントは、PomArc モバイルアプリ（Expo）の機能要件およびUI/UX要件を定義するためのドラフトです。
ユーザー様による編集・追記を前提としています。

## 1. プロジェクト概要
*   **プラットフォーム**: iOS / Android (Expo)
*   **主要な目的**: PC版のPomArcをレイアウトを変更しモバイル版で操作可能にしたもの
機能面はPC版と同じである
閲覧用に特化したものではない

*   **データ構造**: PC版と同様


## 2. 機能要件 (Architecture & Logic)
*現状の実装ステータスに基づく機能定義です。*

### 2.1 データ永続化
*   **DB**: `expo-sqlite` を使用。
*   **Repository Pattern**: Web版と共通のインターフェース (`StorageInterface`) を使用。
*   **現状のステータス**:
    *   Todo, Category, SRSProfile, Session のテーブル作成完了。
    *   CRUD操作 (作成・読み取り・更新・削除) 実装済み。

### 2.2 ドメイン機能
*   **Todo管理**:
    *   タスクの追加、完了/未完了の切り替え、編集、削除。
    *   リスト表示（現在は全件取得のみ）。
*   **スケジュール**:
    *   一日のタスクを時間軸で表示（未実装・プレースホルダーのみ）。
*   **カレンダー**:
    *   月次カレンダー表示（未実装・プレースホルダーのみ）。

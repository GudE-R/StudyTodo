# Web版機能要件整理 (Mobile移植用)

Mobile版への完全な機能移植（パリティ）を実現するため、現在のWeb版 (`apps/web`) の機能を整理しました。
以下の全ての機能をMobile版でも実装することを目標とします。

## 1. Todo管理機能

### 1-1. Todoリスト (`TodoList.tsx`)
- **表示内容**:
  - タイトル
  - 期限（日付・時刻）。期限切れの場合は赤字表示。
  - 優先度アイコン（High: 赤, Medium: 青, Low: なし/グレー）。
  - 完了/未完了のチェックボックス（完了時は取り消し線）。
- **操作**:
  - **ドラッグ&ドロップ**: タスクの順序入れ替え。
  - **完了切り替え**: チェックボックスのタップ。
  - **詳細選択**: タスクタップで詳細/タイマー画面へ（Mobile要検討）。

### 1-2. Todo作成 (`TodoCreateModal.tsx`)
- **入力項目**:
  - タイトル
  - **カテゴリ**: ドロップダウンから選択。
  - **期限**: 日付と時刻の設定 (`datetime-local`)。
  - **優先度**: Low / Medium / High の3段階切り替え。

## 2. テンプレート・設定機能 (`TemplateModal.tsx`)

### 2-1. カテゴリ管理 (`CategoryEditor.tsx`)
- **構造**: 階層構造（ツリー表示）。親カテゴリ・子カテゴリ。
- **操作**:
  - **追加**: ルートカテゴリの追加、または既存カテゴリへのサブカテゴリ追加。
  - **削除**: 下位カテゴリを含めた削除（カスケード）。
  - **展開/折りたたみ**: ツリーの開閉。

### 2-2. SRS (間隔反復) プロファイル (`SRSEditor.tsx`)
- **機能**: 復習間隔の定義セット管理。
- **データ**:
  - 名前（例: "Standard", "Hard Mode"）。
  - **間隔設定**: 日数リスト（カンマ区切り。例: `1, 3, 7, 14`）。
  - **デフォルト設定**: 新規タスク作成時のデフォルトプロファイルを指定可能。

## 3. タイマー・学習記録 (`TimerView.tsx`)

### 3-1. タイマーモード
1.  **Pomodoro**:
    - Focus (25分/50分) + Break (5分/10分) のプリセット切り替え。
    - 円形プログレスバー表示。
    - 完了時の通知とアラート。
2.  **Countdown**:
    - 任意の分数（分単位）を設定してカウントダウン。
3.  **Stopwatch**:
    - カウントアップ計測。

### 3-2. セッション記録
- **保存データ**:
  - 対象Todo（ID/タイトル）。
  - 実施モード（Pomodoro/Countdown/Stopwatch）。
  - **経過時間**（秒）。
- **手動記録**: "Record Session Only" ボタンで、タイマーを回さずに実績のみ保存可能。

### 3-3. アクティビティログ (`ActivityModal.tsx`)
- **一覧表示**: 学習履歴のリスト（新しい順）。
- **表示項目**: タスク名、日時、学習時間。
- **削除**: 履歴の削除機能（確認ステップあり）。

## 4. ホーム画面・可視化 (`Home`)

### 4-1. デイリースケジュール (`DaySchedule.tsx`)
- **タイムライン**: 24時間の垂直タイムライン。
- **タスク表示**: `dueTime` に基づき、タイムライン上にブロック配置。
- **Current Time**: 現在時刻に赤線を入れ、自動スクロールで追従。

### 4-2. カレンダー (`CalendarPane.tsx`)
- **月表示**: 月ごとのカレンダー。
- **インジケーター**:
  - **緑ドット**: その日に学習記録（Session）がある。
  - **オレンジドット**: その日に期限のタスク（Todo）がある。
- **日付選択**: タップで `DaySchedule` の表示日を切り替え。

---

**Mobile版への移植方針:**
- UIはタッチ操作に最適化しつつ、上記ロジックを完全に再現する。
- `react-native-gesture-handler` や専用ライブラリ（DateTimePickerなど）を活用する。

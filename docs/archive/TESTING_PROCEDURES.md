# テスト手順書 (Testing Procedures)

## 1. ログイン (Login)

**前提条件**: アプリがログアウト状態であること。

**テスト手順**:
1. ホーム画面右上の「歯車アイコン」をタップして設定モーダルを開く。
2. 「Log In / Sign Up」ボタン（未ログイン時のみ表示）をタップ。
3. メールアドレスとパスワードを入力。
   - 既存アカウントの場合: 「Log In」を選択して実行。
   - 新規アカウントの場合: 「Sign Up」を選択して実行（メール確認が必要な場合あり）。
4. ログイン成功のメッセージが表示されることを確認。

**確認事項**:
- 設定モーダル内に「LOGGED IN AS: [メールアドレス]」が表示されること。
- 「Log Out」ボタンが表示されること。
- 「Sync Now」ボタンが有効化されること。

## 2. 同期 (Upload: ローカル → クラウド)

**前提条件**: ログイン済みであること。

**テスト手順**:
1. モバイルアプリで新しいTodoを作成する（例: "Mobile Test Task"）。
2. （任意）カテゴリやSRSなどのデータも変更してみる。
3. 設定モーダルの「Sync Now」ボタンをタップする（または自動同期を待つ）。
   - ※リアルタイム同期が有効な場合は、即座に反映される可能性があります。
4. Supabaseのダッシュボード、またはWeb版アプリを確認する。

**確認事項**:
- Web版（またはDB）に、モバイルで作成したタスクが表示されていること。
- 変更内容（タイトル、完了状態など）が一致していること。

## 3. 同期 (Download: クラウド → ローカル)

**前提条件**: ログイン済みであり、Web版（または別端末）が利用可能であること。

**テスト手順**:
1. Web版アプリ（またはSupabase直接操作）で新しいTodoを作成する（例: "Web Test Task"）。
2. モバイルアプリを開く。
3. 設定モーダルの「Sync Now」ボタンをタップする。
   - ※リアルタイム同期が有効な場合、操作なしで反映されるか確認するのも良いテストです。

**確認事項**:
- モバイルアプリのTodoリストに、Web版で作成したタスクが表示されること。

## 4. リアルタイム同期 (Realtime Sync)

**前提条件**: ログイン済みであり、ネットワークに接続されていること。

**テスト手順**:
1. Web版とモバイル版を同時に開いておく。
2. Web版でタスクを完了にする。
3. モバイル版で即座に（数秒以内に）タスクが完了状態になるか確認する。

**確認事項**:
- 手動で同期ボタンを押さなくても、変更が反映されること。

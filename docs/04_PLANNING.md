# PomArc Future Roadmap
最終更新: 2025-12-11

本ドキュメントは、PomArcの将来的な開発計画、および保留中のアイデア（バックログ）を管理します。

## Phase 1: 基盤強化とモバイル最適化 (Current)
- [x] **UI構造の整理**: 設定・テンプレートの分離、アクセス性の向上。
- [x] **ダークモード完全対応**: 全画面・コンポーネントでの表示崩れ修正。
- [x] **アクティビティ機能**: 基本的な統計と履歴の実装。
- [ ] **PWA化**: manifest.jsonの整備、サービスワーカーによるキャッシュ戦略。

## Phase 2: データ保全と利便性
- [ ] **データ・エクスポート/インポート**: JSON/CSV形式でのバックアップ機能。
- [ ] **通知機能**: ブラウザ通知によるタイマー終了やリマインダー通知。

## Phase 3: Pro機能 (Cloud Sync)
*将来的なサブスクリプション要素*
- [ ] **ユーザー認証**: Supabase Auth等の導入。
- [ ] **クラウド同期**: 複数端末間でのデータ同期。
- [ ] **アドバンスドレポート**: より詳細なグラフ、相関分析。

## Backlog / Ideas
*   **ゲーミフィケーション**: タスク完了や学習時間に応じたバッジ・レベル機能。
*   **フォーカスBGM**: タイマー中の環境音再生機能。
*   **ソーシャル**: 学習時間のシェア機能。
*   **タグ機能**: カテゴリとは別の柔軟なタグ付け。

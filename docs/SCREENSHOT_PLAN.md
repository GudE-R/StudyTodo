# iOS スクリーンショット撮影計画

App Store にアプリを提出するには、特定の解像度のスクリーンショットが必須です。以下のいずれかの方法で準備します。

## 1. 必要なスクリーンショットのサイズ (2026年最新)

App Store Connect では以下のサイズが**必須**となる場合が多いです。

### iPhone (6.5 / 6.7 インチ)
いずれか1セット必須（最大10枚、最低3枚推奨）。
- **6.5 インチ**: 1242 x 2688 px (iPhone 14 Plus, 13 Pro Max 等)
- **6.7 インチ**: 1290 x 2796 px (iPhone 15 Pro Max, 16 Pro Max 等)
  - *注: 現在の Apple の要件では、最新の Pro Max モデル (6.7") が推奨されています。*

### iPad (13 / 12.9 インチ)
iPad版を提供する場合に必須。
- **13 インチ / 12.9 インチ**: 2048 x 2732 px (iPad Pro 12.9-inch 6th gen / iPad Pro 13-inch M4 等)

## 2. 撮影方法

### 方法 A: クラウド Mac を使用する場合 (今回の方針)
VNC等でクラウド Mac に接続し、Xcode シミュレータを使用して正確な解像度で撮影します。

1.  **Xcode Simulator の起動**:
    - クラウド Mac 上で Xcode を開き、メニューバーの `Xcode` -> `Open Developer Tool` -> `Simulator` を選択。
    - シミュレータのメニュー `File` -> `Open Device` から、対象のデバイスを選択します。
      - iPhone: **iPhone 16 Pro Max** (6.7") または **iPhone 14 Plus** (6.5")
      - iPad: **iPad Pro (12.9-inch) (6th generation)** または **iPad Pro (13-inch)**
2.  **プロジェクトの起動**:
    - ターミナルで `cd apps/mobile` を実行。
    - `npx expo start` を実行。
    - **`i`** キーを押してシミュレータにアプリをインストール・起動（インターネット経由のため初回は少し時間がかかります）。
3.  **撮影と保存**:
    - シミュレータのメニュー `File` -> `Save Screen Shot` (Command + S) を実行。
    - デスクトップに `Screen Shot ...` というファイル名で保存されます。
4.  **ファイルの転送**:
    - クラウド Mac からご自身の PC へ画像をダウンロードします（ファイル転送機能、ブラウザ経由のクラウドストレージ、または Git 等を利用）。

### 方法 B: Mac を使用しない場合 (推奨)
物理デバイス（iPhone）とオンラインの生成ツールを組み合わせる方法です。

1.  **実機で撮影**:
    - 手持ちの iPhone (どのモデルでも可) でアプリを起動し、必要な画面のスクリーンショットを撮影します。
    - 撮影した画像を PC (Linux) に転送します。
2.  **オンラインジェネレータで加工**:
    - 以下のツールを使用して、撮影した画像を「最新デバイスのフレーム」にはめ込み、必須解像度で書き出します。
    - **AppScreens** (https://appscreens.com/): 複数の解像度を一度に生成可能。
    - **AppMockUp Studio** (https://app-mockup.com/): ブラウザ上で完結する高機能ツール。
    - **Hotpot.ai** (https://hotpot.ai/design/app-store-screenshot-generator): シンプルな操作で生成可能。

## 3. 推奨される画面構成 (5枚程度)

1.  **Home (Today)**: 今日のタスクとスケジュールが見える画面。
2.  **Calendar/Activity**: ヒートマップや統計グラフが見える画面。
3.  **Focus/Timer**: ポモドーロタイマーが動作している画面。
4.  **Todo Detail/SRS**: タスク詳細や忘却曲線の設定が見える画面。
5.  **Settings/Dark Mode**: ダークモードの美しさが伝わる画面。

## 4. アプリプレビュー (App Preview)

アプリプレビューは、ストア掲載ページでスクリーンショットの前に表示される **「最大30秒の紹介動画」** です。

- **役割**: アプリの実際の動作や使い心地を動画で伝え、ダウンロード率を高めるために非常に効果的です。
- **要件**:
    - 長さ: 15秒 〜 30秒
    - 内容: 実際のアプリ画面のキャプチャのみ（人が操作している様子や説明などは含められません）
- **優先度**: **任意（オプション）** です。まずはスクリーンショットを揃えることを優先し、余裕があれば作成を検討してください。

> [!TIP]
> スクリーンショットを撮影する際は、ある程度データ（タスクや記録）が入っている状態の方が、ユーザーにアプリの良さが伝わりやすくなります。

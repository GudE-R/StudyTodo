# 01. ホーム画面ワイヤーフレーム

アプリのホーム画面構造（上→下）を示します。各ブロックは固定位置で、日付バーと中央領域が日々の操作の中心です。

```mermaid
flowchart TB
  A[最上部: 広告バナー] --> B[日付バー: 左=プロフィール | 中央=日付 | 右=設定]
  B --> C{中央領域}
  C -->|左カラム| C1[Todoリスト]
  C -->|右カラム| C2[Dayスケジュール]
  C --> D[中央下段: カレンダー]
  D --> E[最下部: テンプレ作成 | Todo作成 | レポート]
```

補足
- 「/」で区切られた要素は同一行に並列配置されます。
- カレンダーの日付を変更すると、Todo/Dayスケジュールの表示日も同期します。

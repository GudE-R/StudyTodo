# PomArc 開発計画 (Future)

これからの開発計画、ロードマップ、およびアイデア（バックログ）を管理するドキュメントです。

## 1. ロードマップ (Roadmap)
今後の開発フェーズと主要なゴールです。「PCファースト」の方針に基づき再編しました。

### フェーズ 1: 基盤強化とPCダッシュボード化 (完了)
- [x] **UI構造の整理**: 設定・テンプレートの分離、アクセス性の向上。
- [x] **ダークモード完全対応**: 全画面・コンポーネントでの表示崩れ修正。
- [x] **アクティビティ機能**: 基本的な統計と履歴の実装。
- [x] **PCダッシュボードレイアウト**: 全画面3カラム構成 (Todo 30% / Schedule 30% / Calendar 40%)。

### フェーズ 2: PC版の生産性向上 (完了)
Web版を「最強のデスクトップツール」として完成させます。
- [x] **キーボードショートカット**: タイマー操作、Todo作成などをキーボードのみで完結。
- [x] **デスクトップ通知**: ブラウザ通知 API を使用したタイマー終了通知。
- [x] **データ・エクスポート/インポート**: JSON/CSV形式でのバックアップ機能。
- [x] **ヒートマップの高度化**: 分析機能の強化。
- [x] ~~週間レポート機能~~ (スキップ)

### フェーズ 3: クラウド同期とモバイル展開 (In Progress)
モバイル対応への布石として、データ基盤を刷新してからNativeアプリへ移行します。
- [x] **Mobile版クラウド同期**: Web版で実装した同期ロジック (`useSync`) をMobile版にも移植し、データの完全同期を実現する。
- [ ] **リアルタイム同期**: Supabase Realtimeを利用して、変更を即座に反映させる。
- [ ] **オフライン対応**: Mobile/Web共に、オフライン時のデータ作成とオンライン復帰時の同期を堅牢にする。
- [x] **Nativeモバイルアプリ開発**: React Native (Expo) によるiOS/Androidアプリ開発（Todo, Schedule, Calendar, Template, Activity, Timer 機能実装完了）。

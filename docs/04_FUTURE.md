# PomArc 開発計画 (Future)

これからの開発計画、ロードマップ、およびアイデア（バックログ）を管理するドキュメントです。

## 1. ロードマップ (Roadmap)
今後の開発フェーズと主要なゴールです。

### フェーズ 1: 基盤強化とモバイル最適化 (現在)
- [x] **UI構造の整理**: 設定・テンプレートの分離、アクセス性の向上。
- [x] **ダークモード完全対応**: 全画面・コンポーネントでの表示崩れ修正。
- [x] **アクティビティ機能**: 基本的な統計と履歴の実装。
- [ ] **モバイルレイアウトの最適化** (詳細未定)

### フェーズ 2: データ保全と利便性
- [ ] **データ・エクスポート/インポート**: JSON/CSV形式でのバックアップ機能。
- [ ] **週間レポート機能**: 学習効率の分析など。
- [ ] **ヒートマップの高度化**
- [ ] **通知機能**: ブラウザ通知によるタイマー終了やリマインダー通知。
- [ ] **キーボードショートカット**: PC利用時の効率化。

### フェーズ 3: モバイルアプリ化 / PWA (将来)
- [ ] **PWA化**: manifest.jsonの整備、Service Worker、オフライン強化。
- [ ] **ユーザー認証**: Supabase Auth等の導入 (Pro機能)。
- [ ] **クラウド同期**: 複数端末間でのデータ同期 (Pro機能)。

## 2. バックログ / アイデア (Backlog)

- [ ] コンポーネントの再利用性向上 (Button, Inputなど)

### 機能アイデア
- **ゲーミフィケーション**: タスク完了や学習時間に応じたバッジ・レベル機能。
- **フォーカスBGM**: タイマー中の環境音再生機能。
- **ソーシャル**: 学習時間のシェア機能。
- **タグ機能**: カテゴリとは別の柔軟なタグ付け。
- 現在のSRS回数を表示可能 (Todo詳細)
- モバイル版ではTodoリスト、スケジュール、カレンダーをタップで拡大表示可能

# PomArc 開発計画 (Future)

これからの開発計画、ロードマップ、およびアイデア（バックログ）を管理するドキュメントです。

## 1. ロードマップ (Roadmap)
今後の開発フェーズと主要なゴールです。「PCファースト」の方針に基づき再編しました。

### フェーズ 1: 基盤強化とPCダッシュボード化 (完了)
- [x] **UI構造の整理**: 設定・テンプレートの分離、アクセス性の向上。
- [x] **ダークモード完全対応**: 全画面・コンポーネントでの表示崩れ修正。
- [x] **アクティビティ機能**: 基本的な統計と履歴の実装。
- [x] **PCダッシュボードレイアウト**: 全画面3カラム構成 (Todo 30% / Schedule 30% / Calendar 40%)。

### フェーズ 2: PC版の生産性向上 (完了)
Web版を「最強のデスクトップツール」として完成させます。
- [x] **キーボードショートカット**: タイマー操作、Todo作成などをキーボードのみで完結。
- [x] **デスクトップ通知**: ブラウザ通知 API を使用したタイマー終了通知。
- [x] **データ・エクスポート/インポート**: JSON/CSV形式でのバックアップ機能。
- [x] **ヒートマップの高度化**: 分析機能の強化。
- [x] **Dayスケジュールの詳細化**: 30分単位の表示と操作に対応。 (2025-12-30)
- [x] ~~週間レポート機能~~ (スキップ)

### フェーズ 3: クラウド同期とモバイル展開 (In Progress)
モバイル対応への布石として、データ基盤を刷新してからNativeアプリへ移行します。
- [x] **Mobile版クラウド同期**: Web版で実装した同期ロジック (`useSync`) をMobile版にも移植し、データの完全同期を実現する。
- [x] **リアルタイム同期**: Supabase Realtimeを利用して、Web/Mobile間の変更を即座に反映させる。
- [/] **オフライン対応**: Mobile/Web共に、オフライン時のデータ作成とオンライン復帰時の同期を堅牢にする。 (進行中: ローカルファースト基盤は完了)
- [x] **Nativeモバイルアプリ開発**: React Native (Expo) によるiOS/Androidアプリ開発（Todo, Schedule, Calendar, Template, Activity, Timer 機能実装完了）。

## 2. バックログ / アイデア (Backlog)
まだ具体的な計画には入っていないアイデアや、技術的な課題です。

### リファクタリング / 技術的負債
- [ ] コンポーネントの再利用性向上 (Button, Inputなど)
- [x] **Web/Mobile型定義の統一**: Web版の独自型定義を廃止し、`packages/shared` に統合する。
- [x] **Web版のShared導入**: Webアプリの依存関係に `packages/shared` を追加し、共通ロジックを利用可能にする。
- [x] **テストコードの導入**: Vitest/Jest による各パッケージのテスト環境構築。 (完了 2025-12-30)
- [ ] テストコードの拡充 (Unit/E2E)
- [ ] Androidエミュレーターでの動作検証とテスト環境の構築

### 機能アイデア
- **ゲーミフィケーション**: タスク完了や学習時間に応じたバッジ・レベル機能。
- **フォーカスBGM**: タイマー中の環境音再生機能。
- **ソーシャル**: 学習時間のシェア機能。
- **タグ機能**: カテゴリとは別の柔軟なタグ付け。
- **Todo詳細**: 現在のSRS回数を表示可能にする。
- **自動スケジュール連携**: 時間指定（開始/終了時間）でTodoを作成した場合、スケジュール（バーチカル）にも自動で反映・表示する仕組み。 (Web/Mobile両方)
- **新UI画面の検討**: カレンダーの配置場所や、より効率的な3カラム構成の模索。
- **Pro版（有料機能）の検討**: 追加機能やプレミアムコンテンツの切り分け。

### 今後の改善案
- [x] **オフラインキューの堅牢化**: ネットワーク切断時の変更をキューイングし、復帰時に確実に送信する仕組み。(実装完了 2025-12-30)
- **モバイル版レイアウトの更なる改善**: 各カラムをタップまたはスワイプした際に、80%程度の大きさで拡大表示されるインタラクションの実装。
- **Todo詳細画面の改良**: Web版の表示ブラッシュアップおよび、モバイル版での詳細確認機能の実装。

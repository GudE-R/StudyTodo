## 2. バックログ / アイデア (Backlog)
まだ具体的な計画には入っていないアイデアや、技術的な課題です。

### リファクタリング / 技術的負債
- [ ] コンポーネントの再利用性向上 (Button, Inputなど)
- [x] **Web/Mobile型定義の統一**: Web版の独自型定義を廃止し、`packages/shared` に統合する。
- [x] **Web版のShared導入**: Webアプリの依存関係に `packages/shared` を追加し、共通ロジックを利用可能にする。
- [x] **テストコードの導入**: Vitest/Jest による各パッケージのテスト環境構築。 (完了 2025-12-30)
- [x] **共有コードの拡充**: `mapper`, `syncCore`, `date utils` を `packages/shared` に統合し、Web/Mobile間で共通化。 (完了 2026-01-01)
- [x] **テストフレームワークのVitest統一**: Mobile版をJestからVitestに移行。 (完了 2026-01-01)
- [ ] テストコードの拡充 (Unit/E2E) - 共有コードのテストは追加済み、コンポーネントテストは今後
- [x] Androidエミュレーターでの動作検証 and テスト環境の構築 (2026-01-01)

### 機能アイデア
- **ゲーミフィケーション**: タスク完了や学習時間に応じたバッジ・レベル機能。
- **フォーカスBGM**: タイマー中の環境音再生機能。
- **ソーシャル**: 学習時間のシェア機能。
- **タグ機能**: カテゴリとは別の柔軟なタグ付け。
- **Todo詳細**: 現在のSRS回数を表示可能にする。
- **自動スケジュール連携**: 時間指定（開始/終了時間）でTodoを作成した場合、スケジュール（バーチカル）にも自動で反映・表示する仕組み。 (Web/Mobile両方)
- **新UI画面の検討**: カレンダーの配置場所や、より効率的な3カラム構成の模索。
- **Pro版（有料機能）の検討**: 追加機能やプレミアムコンテンツの切り分け。

### 今後の改善案
- **モバイル版レイアウトの更なる改善**: 各カラムをタップまたはスワイプした際に、80%程度の大きさで拡大表示されるインタラクションの実装。
- **Todo詳細画面の改良**: Web版の表示ブラッシュアップおよび、モバイル版での詳細確認機能の実装。

## 開発方針ポリシー
**並行開発からWeb先行開発へ**: 
同時開発による複雑性を避けるため、まずWeb版を「Pro版のビジネスモデル（広告・制限・決済）」を含めて完成・リリースします。その後、安定したロジックをモバイル版に移植・同期させる方針をとります。

# StudyTodo ゲーミフィケーション計画書

最終更新: 2026-03-08
ステータス: **ドラフト（骨組み）**

---

## 1. 概要

StudyTodoにゲーミフィケーション要素を導入し、ユーザーの学習モチベーションと継続率を向上させる。
本ドキュメントでは、バッジ・レベル・ストリークなどの仕組みを設計する。

> PRO_PLAN.md の機能 #9 として参照。無料/Pro の線引きは本ドキュメントで検討する。

---

## 2. 目標

- **継続率の向上**: 毎日の学習習慣を強化する仕組み
- **達成感の提供**: 小さな目標を達成するたびにフィードバックを与える
- **自然な課金導線**: 一部のゲーミフィケーション要素をPro限定にすることで転換率向上

---

## 3. 機能候補

### 3.1 ストリーク（連続学習記録）

| 項目 | 内容 |
|------|------|
| 概要 | 連続で学習した日数をカウント |
| 表示場所 | ホーム画面、プロフィール |
| 無料/Pro | **無料** |
| 備考 | DuolingoやGitHubの草に似た仕組み |

### 3.2 バッジ（実績）

| 項目 | 内容 |
|------|------|
| 概要 | 特定の条件を達成するとバッジを獲得 |
| 例 | 「初めてのタスク完了」「7日連続学習」「100時間学習」 |
| 無料/Pro | 基本バッジは**無料**、レアバッジは**Pro限定**（要検討） |
| 備考 | バッジのデザインが重要 |

### 3.3 レベル / 経験値（XP）

| 項目 | 内容 |
|------|------|
| 概要 | 学習活動でXPを獲得し、レベルアップ |
| XP獲得条件 | タスク完了、タイマー使用、SRS復習 |
| 無料/Pro | **要検討** |
| 備考 | レベルに応じたテーマ解放なども可能 |

### 3.4 学習カレンダー（ヒートマップ）

| 項目 | 内容 |
|------|------|
| 概要 | GitHubの草のような学習量のヒートマップ |
| 表示場所 | プロフィール画面、統計画面 |
| 無料/Pro | **無料** |
| 備考 | 既存の学習履歴データを活用可能 |

## 4. 無料/Pro の線引き（案）

| 要素 | 無料 | Pro |
|------|------|-----|
| ストリーク | ✅ | ✅ |
| 基本バッジ | ✅ | ✅ |
| レアバッジ | ❌ | ✅ |
| レベル / XP | ✅ | ✅ |
| 学習カレンダー | ✅ | ✅ |
| カスタムアバター | ❌ | ✅ |

> **方針**: ゲーミフィケーションの基本体験は無料で提供し、コレクション要素やカスタマイズをPro限定にする。
